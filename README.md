# vehicle
An ontology that describes several classes of vehicles and their properties as relevant to appearance, conditions, maintenance and intended use.

Initial classes suggested from various sources 

Year
Make
Model
Color
VIN
Mileage
Engine Type
Drive Train: Manual, Automatic, Other
Condition: New, Used, Original Vintage or Classic, Re-Created, Restored, Parts Vehicle, in Process of Being Restored 
[note there is a difference between a 'restoration' which implies a significant percentage of original parts)
